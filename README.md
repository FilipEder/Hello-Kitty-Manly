# 🎀 Hello Kitty 3D - The Peak of Masculinity 💪

![Hello Kitty Manly Meme](HelloKitty.jpg) 

## 💀 O projektu
Společnost ti bude tvrdit, že ultimátní test mužnosti je zvednout nový osobák na mrtvý tah. Omyl. Skutečný alfa vývojář ví, že ten pravý hardcore flex je spojit nekompromisní backendovou sílu **ASP.NET Core MVC** s renderováním 3D modelu Hello Kitty pomocí **Three.js**. 

Tento projekt je nezvratným důkazem, že růžová je nová černá, a že servírovat roztomilou kočičku ve WebGL přes robustní C# architekturu je to nejdrsnější, co můžeš se svým kódem udělat.

## 🚀 Features (Co to umí)
*   **Aggressively Pink Background:** Barva, která otestuje tvou dominanci.
*   **Smooth 3D Rotation:** Hello Kitty nekompromisně rotující v 60 FPS.
*   **C# Backend Muscle:** Architektura pevnější než tvůj opasek na těžké dřepy.
*   **Chad Lighting:** Dokonalé 3D nasvícení, které by jí záviděl každý kulturista na pódiu.

## 🛠 Tech Stack
*   **ASP.NET Core MVC & C#** - Hrubá síla na backendu. Žádné kompromisy.
*   **Three.js** - Pro ten pravý 3D frontendový hardcore zážitek.
*   **JavaScript / HTML / CSS** - Klasická trojka pro to správné vykreslení.

## 🏋️‍♂️ Jak to rozběhnout (Installation)
Pro ty, co mají dost odvahy spustit tento C# masterpiece na vlastním stroji:

```bash
# 1. Klonuj tento mocný repozitář
git clone [https://github.com/tvoje-jmeno/hello-kitty-manly-mvc.git](https://github.com/tvoje-jmeno/hello-kitty-manly-mvc.git)

# 2. Vstup do arény
cd hello-kitty-manly-mvc

# 3. Pre-workout (obnovení NuGet balíčků)
dotnet restore

# 4. Zahřívací série (build)
dotnet build

# 5. Těžká váha - jedem! (spuštění serveru)
dotnet run
